# Customer Support Intent Classification

## Project Overview

This is a beginner-level data annotation project focused on classifying customer support messages according to their intended purpose.

## Objective

The objective of this project is to demonstrate the process of reading, interpreting, and consistently assigning predefined labels to text data.

## Annotation Categories

The dataset will contain customer messages classified into categories such as:

- Billing
- Account Access
- Password Reset
- Cancellation
- Delivery
- Refund
- Technical Issue
- General Question

## Skills Demonstrated

- Text classification
- Data annotation
- Following annotation guidelines
- Attention to detail
- Data quality review
- Consistent labeling
- Documentation
