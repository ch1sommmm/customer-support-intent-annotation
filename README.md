# Customer Support Intent Classification

## Project Overview

This is a beginner-level data annotation project focused on classifying customer support messages according to their primary intent.

The project demonstrates the process of reading, interpreting, and consistently labeling text data using predefined annotation categories.

## Objective

The objective of this project is to demonstrate practical skills in:

- Text classification
- Intent annotation
- Following annotation guidelines
- Reasoning and decision-making
- Consistent labeling
- Quality-focused data annotation

## Dataset

The dataset contains 10 simulated customer support messages representing common customer service scenarios.

Each message was reviewed and assigned:

- A primary intent
- A confidence level
- A short explanation supporting the annotation decision

## Annotation Categories

The project uses the following intent categories:

- Billing
- Account Access
- Password Reset
- Delivery
- Cancellation
- Technical Issue
- Refund
- General Question

## Annotation Process

Each customer message was reviewed individually using the following process:

1. Read the entire customer message.
2. Identify the customer's primary reason for contacting support.
3. Select the most appropriate predefined intent category.
4. Assign a confidence level based on how clearly the message matched the category.
5. Provide a brief reason explaining the annotation decision.
6. Review the annotation for consistency with the project guidelines.

## Quality Control

To improve annotation consistency, I used a predefined annotation guideline document.

The guidelines helped ensure that:

- Each message received one primary intent.
- Labels were assigned based on the customer's main reason for contacting support.
- Individual keywords were not used as the only basis for classification.
- Annotations were reviewed for consistency.
- Ambiguous messages were assigned an appropriate confidence level.
